大家都在比功能。「有看板嗎？有重複任務嗎？有 API 嗎？」但這些問題其實沒問到重點。

真正的問題是：**早上七點你打開什麼 app 來決定今天要做什麼？**

如果你打開 Notion，你看到的是一個工作區。頁面、資料庫、wiki、會議記錄、專案追蹤器、三個季度前有人分享的那個 OKR 模板。你的任務藏在某個角落，你得自己找。

如果你打開 First Light，你看到的是一份簡報。今天發生什麼事、什麼最重要、什麼可以等。從這裡開始。

兩種方式都可以，只是在解決不同的問題。

## 功能比較

| 功能 | First Light | Notion |
|------|------------|--------|
| AI 每日簡報 | 內建（Daily Edition） | 沒有 |
| AI 任務規劃 | 幫你安排一天、安排一週 | AI 區塊（摘要、寫作） |
| MCP 整合 | 原生支援，Claude 直接讀寫任務 | 沒有 |
| 任務管理 | 專門設計（今天/明天/未來7天/收件匣） | 資料庫加任務模板 |
| 日曆 | 內建＋Google 日曆同步 | 內建日曆檢視 |
| 專注計時 | 內建番茄鐘 | 沒有 |
| 習慣追蹤 | 內建 | 要自己建資料庫 |
| 艾森豪矩陣 | 內建（The Sift） | 要自己套模板 |
| 知識管理 | 筆記（可連結任務） | 完整 wiki＋資料庫 |
| 團隊協作 | Groups（測試中） | 完整團隊工作區 |
| 價格 | 免費 / $5 / $9 | 免費 / $10 / $12 |

## First Light 贏在哪裡

**早晨的清晰感。** Daily Edition 讀你的日曆、檢查截止日期、知道你的做事節奏，然後每天早上寫一份簡報給你。Notion 沒有類似的功能。你可以自己建一個儀表板，但儀表板還是需要你自己判讀。Daily Edition 幫你判讀好了。

**AI 真的能動你的資料。** First Light 支援 MCP。跟 Claude 說「把週五的事全部移到週一」，它就真的做了，直接在 First Light 裡面改。Notion 的 AI 可以摘要、寫文字，但沒辦法根據你跟 Claude 的對話重新安排你的整週行程。

**馬上開始做事。** 打開 First Light，看到今天的任務，就開始做。介面故意做得簡單，因為規劃應該花 90 秒，不是花 15 分鐘客製化儀表板。

**語音跟截圖建立任務。** 說「明天買菜」或拍一張白板的照片，First Light 就會解析然後建立結構化的任務。Notion 需要你打開頁面、找到正確的資料庫、自己打字。

## Notion 贏在哪裡

**知識管理。** 如果你需要 wiki、文件、關聯式資料庫、跨部門共享的工作區，Notion 是真的很強。First Light 有筆記功能，但它不是要當你的企業 wiki。

**團隊協作。** Notion 可以處理多人工作區、權限、留言、標記、共享資料庫。First Light 的 Groups 還在測試階段，目前比較適合小團隊。

**彈性。** Notion 幾乎什麼都能建。專案追蹤、CRM、內容日曆、庫存系統。First Light 故意不做這些。它只做一件事——每日規劃——然後把這件事做到最深。

## 怎麼選

**選 First Light** 如果你最大的困擾是「事情太多，每天早上都不知道從哪裡開始」。First Light 就是為了那個時刻設計的——從醒來到開始工作之間的轉換。

**選 Notion** 如果你最大的困擾是「團隊的知識散落各處，需要一個統一的地方」。Notion 是工作區，是資訊集中的地方。

**兩個都用** 如果你需要團隊知識庫（Notion）同時又需要一個真正幫你排優先順序的個人日程規劃工具（First Light）。它們解決的是不同的問題，其實不太重疊。

## MCP 是關鍵差異

Notion 不支援 MCP。如果你用 Claude、ChatGPT 或其他 AI 助理，它沒辦法直接讀取你 Notion 裡的任務。你只能複製貼上，或用一些勉強能用的第三方整合。

First Light 有原生的 MCP 伺服器。你的 AI 助理可以直接讀你的任務、建新任務、重新排程、跑每週回顧——全部透過直接連線。不用複製貼上，不用中間層。

如果你是已經每天都在跟 AI 對話的人，你的規劃工具應該是那個對話的一部分，不是另一個要切過去的分頁。
