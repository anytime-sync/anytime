みんな機能を比べます。「カンバンはある？繰り返しタスクは？APIは？」でも、それらの質問は本質を見逃しています。

本当の質問は：**朝7時に「今日何をすべきか」を決めるために、何を開きますか？**

Notionを開くと、ワークスペースが見えます。ページ、データベース、Wiki、会議メモ、プロジェクトトラッカー、3四半期前に誰かが共有したOKRテンプレート。タスクはどこかにあります。自分で見つけなければなりません。

First Lightを開くと、ブリーフィングが見えます。今日何が起こるか、何が重要か、何が待てるか。ここから始めましょう。

どちらのアプローチも有効です。ただ、異なる問題を解決しているだけです。

## 機能比較

| 機能 | First Light | Notion |
|------|------------|--------|
| AIデイリーブリーフィング | 内蔵（Daily Edition） | なし |
| AIタスクプランニング | 一日を計画、一週間を計画 | AIブロック（要約、執筆） |
| MCP統合 | ネイティブ対応 | なし |
| タスク管理 | 専用設計（今日/明日/7日間/インボックス） | データベース＋タスクテンプレート |
| カレンダー | 内蔵＋Googleカレンダー同期 | 内蔵カレンダービュー |
| フォーカスタイマー | 内蔵ポモドーロ | なし |
| 習慣トラッキング | 内蔵 | 手動でデータベース構築 |
| 価格 | 無料 / $5 / $9 | 無料 / $10 / $12 |

## First Lightが優れている点

**朝の明確さ。** Daily Editionはカレンダーを読み、締め切りを確認し、あなたのパターンを把握した上で、毎朝ブリーフィングを書いてくれます。Notionには同等の機能がありません。

**AIがデータに直接触れる。** First LightはMCPに対応しています。Claudeに「金曜日の予定を全部月曜日に移して」と言えば、実際にFirst Light内で実行されます。NotionのAIはページを要約したりテキストを生成できますが、Claudeとの会話に基づいて一週間を再編成することはできません。

**すぐに行動開始。** First Lightを開き、今日のタスクを見て、作業開始。インターフェースは意図的にシンプルです。計画は90秒で終わるべきで、ダッシュボードのカスタマイズに15分かけるものではありません。

## Notionが優れている点

**ナレッジマネジメント。** Wiki、ドキュメント、リレーショナルデータベース、共有ワークスペースが必要なら、Notionは本当に優秀です。

**チームコラボレーション。** Notionは権限管理、コメント、メンション、共有データベースを備えた多人数ワークスペースを処理できます。

**柔軟性。** Notionはほぼ何でも構築できます。First Lightは意図的にそうしません。一つのこと——デイリープランニング——を深く追求します。

## どう選ぶか

**First Lightを選ぶ** 最大の不満が「やることが多すぎて、毎朝どこから始めればいいかわからない」なら。

**Notionを選ぶ** 最大の不満が「チームの知識があちこちに散らばっていて、一箇所にまとめたい」なら。

**両方使う** チームのナレッジベース（Notion）と、実際に優先順位を付けてくれる個人プランナー（First Light）の両方が必要なら。
