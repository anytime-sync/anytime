大家都在比功能。「有看板吗？有重复任务吗？有 API 吗？」但这些问题其实没问到重点。

真正的问题是：**早上七点你打开什么 app 来决定今天要做什么？**

如果你打开 Notion，你看到的是一个工作区。页面、数据库、wiki、会议记录、项目追踪器、三个季度前有人分享的那个 OKR 模板。你的任务藏在某个角落，你得自己找。

如果你打开 First Light，你看到的是一份简报。今天发生什么事、什么最重要、什么可以等。从这里开始。

两种方式都可以，只是在解决不同的问题。

## 功能比较

| 功能 | First Light | Notion |
|------|------------|--------|
| AI 每日简报 | 内建（Daily Edition） | 没有 |
| AI 任务规划 | 帮你安排一天、安排一周 | AI 区块（摘要、写作） |
| MCP 整合 | 原生支持，Claude 直接读写任务 | 没有 |
| 任务管理 | 专门设计（今天/明天/未来7天/收件箱） | 数据库加任务模板 |
| 日历 | 内建＋Google 日历同步 | 内建日历视图 |
| 专注计时 | 内建番茄钟 | 没有 |
| 习惯追踪 | 内建 | 要自己建数据库 |
| 知识管理 | 笔记（可连结任务） | 完整 wiki＋数据库 |
| 团队协作 | Groups（测试中） | 完整团队工作区 |
| 价格 | 免费 / $5 / $9 | 免费 / $10 / $12 |

## First Light 赢在哪里

**早晨的清晰感。** Daily Edition 读你的日历、检查截止日期、知道你的做事节奏，然后每天早上写一份简报给你。Notion 没有类似的功能。你可以自己建一个仪表板，但仪表板还是需要你自己判读。Daily Edition 帮你判读好了。

**AI 真的能动你的数据。** First Light 支持 MCP。跟 Claude 说「把周五的事全部移到周一」，它就真的做了，直接在 First Light 里面改。Notion 的 AI 可以摘要、写文字，但没办法根据你跟 Claude 的对话重新安排你的整周行程。

**马上开始做事。** 打开 First Light，看到今天的任务，就开始做。界面故意做得简单，因为规划应该花 90 秒，不是花 15 分钟自定义仪表板。

## Notion 赢在哪里

**知识管理。** 如果你需要 wiki、文档、关联式数据库、跨部门共享的工作区，Notion 是真的很强。First Light 有笔记功能，但它不是要当你的企业 wiki。

**团队协作。** Notion 可以处理多人工作区、权限、评论、标记、共享数据库。First Light 的 Groups 还在测试阶段，目前比较适合小团队。

**灵活性。** Notion 几乎什么都能建。项目追踪、CRM、内容日历、库存系统。First Light 故意不做这些。它只做一件事——每日规划——然后把这件事做到最深。

## 怎么选

**选 First Light** 如果你最大的困扰是「事情太多，每天早上都不知道从哪里开始」。

**选 Notion** 如果你最大的困扰是「团队的知识散落各处，需要一个统一的地方」。

**两个都用** 如果你需要团队知识库（Notion）同时又需要一个真正帮你排优先顺序的个人日程规划工具（First Light）。
