다들 기능을 비교합니다. "칸반 있어? 반복 작업 돼? API 있어?" 하지만 이런 질문들은 핵심을 놓치고 있습니다.

진짜 질문은: **아침 7시에 오늘 뭘 해야 할지 정하려고 뭘 여시나요?**

Notion을 열면 워크스페이스가 보입니다. 페이지, 데이터베이스, 위키, 회의록, 프로젝트 트래커, 세 분기 전에 누가 공유한 OKR 템플릿. 할 일은 어딘가에 있는데, 직접 찾아야 합니다.

First Light를 열면 브리핑이 보입니다. 오늘 무슨 일이 있는지, 뭐가 중요한지, 뭐가 기다릴 수 있는지. 여기서 시작하세요.

둘 다 잘 작동합니다. 그냥 다른 문제를 풀고 있을 뿐입니다.

## 기능 비교

| 기능 | First Light | Notion |
|------|------------|--------|
| AI 데일리 브리핑 | 내장 (Daily Edition) | 없음 |
| AI 할 일 계획 | 하루 계획, 주간 계획 | AI 블록 (요약, 작성) |
| MCP 연동 | 네이티브 지원 | 없음 |
| 할 일 관리 | 전용 설계 (오늘/내일/7일/수신함) | 데이터베이스 + 템플릿 |
| 캘린더 | 내장 + Google 캘린더 동기화 | 내장 캘린더 뷰 |
| 집중 타이머 | 내장 포모도로 | 없음 |
| 습관 추적 | 내장 | 직접 데이터베이스 구축 |
| 가격 | 무료 / $5 / $9 | 무료 / $10 / $12 |

## First Light가 좋은 점

**아침의 명확함.** Daily Edition은 캘린더를 읽고, 마감일을 확인하고, 패턴을 파악해서 매일 아침 브리핑을 써줍니다. Notion에는 동등한 기능이 없습니다.

**AI가 실제 데이터를 건드린다.** First Light는 MCP를 지원합니다. Claude에게 "금요일 일정 전부 월요일로 옮겨"라고 하면, 실제로 First Light 안에서 실행됩니다.

**바로 시작.** First Light를 열고, 오늘 할 일을 보고, 바로 시작. 계획은 90초면 끝나야지, 대시보드 커스터마이징에 15분 쓸 게 아닙니다.

## Notion이 좋은 점

**지식 관리.** 위키, 문서, 관계형 데이터베이스, 공유 워크스페이스가 필요하다면 Notion이 정말 훌륭합니다.

**팀 협업.** Notion은 권한, 댓글, 멘션, 공유 데이터베이스를 갖춘 다인 워크스페이스를 처리합니다.

**유연성.** Notion은 거의 뭐든 만들 수 있습니다. First Light는 의도적으로 그렇게 하지 않습니다. 한 가지—데일리 플래닝—만 깊이 있게 합니다.

## 어떻게 선택할까

**First Light 선택:** "할 일이 너무 많아서 매일 아침 어디서 시작해야 할지 모르겠어"가 가장 큰 고민이라면.

**Notion 선택:** "팀 지식이 여기저기 흩어져 있어서 한 곳에 모아야 해"가 가장 큰 고민이라면.

**둘 다 사용:** 팀 지식 베이스(Notion)와 실제로 우선순위를 정해주는 개인 플래너(First Light) 둘 다 필요하다면.
